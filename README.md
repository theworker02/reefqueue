# reefqueue

Reef digests and queue fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/reefqueue/

## Install / run

```bash
git clone https://github.com/theworker02/reefqueue.git
cd reefqueue
node src/cli.js
node --test
```
